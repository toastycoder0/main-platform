# 🚀 BOYA

> Plataforma web de BOYA construida con **Next.js** y **PostgreSQL**. Consiste en un marketplace de productos, un sistema de administración y una sección de gestión de inventarios. Se implementaron integraciones con **tRPC**, **Drizzle ORM** y **BetterAuth**.
